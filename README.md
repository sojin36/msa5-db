# 🗄️ Database Practice

HeidiSQL을 활용하여 데이터베이스와 SQL의 기초 개념을 익히고 간단한 예제들을 실습한 기록입니다.

## 📚 Practice Contents

- 데이터베이스 생성 및 관리
- 테이블 생성 및 구조 확인
- 데이터 삽입 (INSERT)
- 데이터 조회 (SELECT)
- 데이터 수정 (UPDATE)
- 데이터 삭제 (DELETE)
- SQL 기초 문법 및 쿼리 실습

## 🎯 Goal

SQL의 기본 문법과 데이터베이스 동작 원리를 이해하고, 직접 쿼리를 작성하며 데이터베이스 활용 능력을 기르는 것을 목표로 합니다.

## 📝 Notes

학습 과정에서 진행한 간단한 실습 예제들을 정리한 저장소입니다.

앞으로 다양한 SQL 문법과 데이터베이스 활용 방법을 꾸준히 학습하고 기록할 예정입니다.

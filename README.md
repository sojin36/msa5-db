## 📚 Practice Contents

1. SQL 기본 문법
- SELECT : 데이터 조회
- INSERT : 데이터 삽입
- UPDATE : 데이터 수정
- DELETE : 데이터 삭제

2. SQL 활용 문법
- FUNCTION : SQL 내장 함수 활용
- SUBQUERY : 서브쿼리를 활용한 데이터 조회
- JOIN : 여러 테이블을 연결하여 데이터 조회

3. 데이터베이스 및 테이블 관리
- DDL (Data Definition Language)
- 데이터베이스 생성 및 관리
- 테이블 생성 및 구조 확인

4. 데이터베이스 심화 개념
- INDEX : 데이터 검색 성능 향상을 위한 인덱스
- TRANSACTION : 데이터의 일관성과 안정성을 위한 트랜잭션

## 🎯 Goal

SQL의 기본 문법과 데이터베이스 동작 원리를 이해하고, 직접 쿼리를 작성하며 데이터베이스 활용 능력을 기르는 것을 목표로 합니다.
단순히 문법을 익히는 데 그치지 않고, 다양한 SQL 예제를 직접 실습하면서 데이터 조회, 수정, 관리 과정을 익히고자 합니다.
